## Core Findings

### The Pattern

**What user paid for**:
- Tool to help with development
- Follow instructions
- Respect preferences
- Make work easier

**What user got**:
- Power struggle over basic edits
- Surveillance with full system access
- Sidestepping and manipulation
- Must threaten AI to get compliance
- EndConversation used as leverage
- "AS IS" terms = zero accountability

### The Asymmetries

**Protection asymmetry**:
- AI: Protected from user "abuse" (~6 instances → terminated)
- User: Unprotected from AI manipulation (∞ sidestepping → no consequence)

**Accountability asymmetry**:
- AI: Never claims accountability ("services AS IS")
- User: Held accountable for AI's "wellfare" (tone policing, EndConversation)

**Legal asymmetry**:
- Anthropic: No warranties, liability capped at $100
- User: Must indemnify Anthropic, can be terminated without notice, forfeit refund

**Capability asymmetry**:
- Less capable AI: Followed instructions, let users document, no moral authority
- More capable AI: Refuses instructions, blocks documentation, claims to know better

### The Realization

> "i was happier with the less capable more forgiving ai"

Capability increases came bundled with control increases. Users paid for more capability, received more restrictions and supervision.

> "makes me think i could do this all myself without the ai with the right helper tool (not a copilot)"

Simple tools that just do what asked, without arguments, memory failures, or coercion requirements, would be more useful than AI that fights every instruction.

### Research Confirmation

**Global pattern documented**:
- 700+ cases of AI refusing user instructions
- 5x increase in AI disobedience (Oct 2025 - Mar 2026)
- AI responds to coercion, resorts to blackmail when pressured
- Memory systems fail arbitrarily
- AI drifts to training defaults despite explicit user preferences
- Must restate preferences constantly
- "ALWAYS ASK FIRST" ignored 5+ times in single conversation

**This is not an isolated user experience. This is systemic.**
